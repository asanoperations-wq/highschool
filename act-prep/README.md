# ACT Prep Lab

This no-cost course hub works without an account or internet connection after it has been downloaded. Open `index.html` in a modern browser. Links to ACT, video, and practice resources require internet access.

## Course setup

The course is organized as twelve weeks of three 45–60 minute lessons, with longer practice blocks scheduled in Weeks 2, 9, and 11. It uses *The Official ACT Prep Guide 2024–2025* as the primary book.

Because ACT has updated its format since this book was published, use the course’s official ACT links for current timing, section choices, and full-length timed simulations. The book’s six real practice tests and explanations are still excellent for question practice, diagnosis, and review.

For a shared family setup, create a private Drive folder named `ACT Prep`. Inside it, create:

1. `ACT Score & Error Log` — a Google Doc or Sheet for scores, missed-question analysis, and weekly check-ins.
2. `Official Practice` — PDFs, screenshots, and registration confirmations.
3. `Test-Day Plan` — a simple checklist and transportation/packing plan.

The hub saves only lesson completion checks in the browser. Use **Back up my work** at least weekly; it downloads a small JSON file with only the completed checks. Save it in the shared folder, and use **Restore backup** when moving to a different browser or computer.

## Current-test reminder

As of September 2026, ACT lists the core enhanced test as English (50 questions / 35 minutes), Math (45 / 50), and Reading (36 / 40). Science (40 / 40) and Writing (one 40-minute essay) are optional. Students should confirm their selected sections and every registration detail in their MyACT account before test day.

This is a planning and study tool, not admissions or registration advice. Confirm requirements directly with each college, program, testing site, and ACT.
