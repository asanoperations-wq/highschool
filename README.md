# Using this course hub for free

This folder is a no-cost website that works without an account or an internet connection after it has been downloaded. Open `index.html` in a modern browser.

## Best shared setup: course hub + Google Drive

The hub holds the lessons, links, worksheets, and lesson checklist. Lesson checks save automatically in the browser that uses it and remain after the site is closed. It does not collect, upload, or store journal writing, interview notes, or other personal details.

Use the `Back up my work` button at least weekly. It downloads one small `.json` file containing only completed lesson checks; save that file in the shared Drive folder. The `Restore backup` button can put that completion record back into the browser later. Browser data can be cleared during a browser reset or device change, so the backup is important.

For a shared, no-cost record:

1. Create one Google Drive folder called `Career & Life Design`.
2. Share it only with the parent and Ezekiel’s Google accounts.
3. Inside it, create:
   - `Career & Life Journal` — a Google Doc for daily and weekly reflection writing.
   - `Research & Evidence` — a folder for career-comparison notes, source links, and screenshots/PDFs.
   - `Final Portfolio` — a folder for the finished materials.
   - `Weekly Check-In` — a simple Google Doc or Sheet with Weeks 1–12 and one “Done / Discuss” note for each week.

Keep all important writing in the private Google journal. The course hub is the public lesson guide and completion tracker; the backup file and shared Drive folder protect its completion record.

## Privacy

The website does not collect, upload, or store personal writing. Keep the student’s journal, interview notes, and other identifying details in the private Google Drive folder. For informational interviews and job shadows, a parent should help arrange contact and the student should not record private client, patient, student, or customer information.

## Updating the course

The hub is intentionally static, so it has no subscriptions, accounts, ads, or ongoing costs.
